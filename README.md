# VandBHome

Демонстрационен сайт на **измислената** брокерска фирма VandBHome – с публичен сайт, потребителски профили, админ панел и база данни **Neon (Postgres)**, хостван във **Vercel**.

## Страници
| Адрес | Какво е |
|---|---|
| `/` | Продай имот: форма „Вземи оферта“ / „Обяви имота си“, оферти, как работи, числа, най-нови обяви, отзиви, въпроси |
| `/properties` | Търси имот: продажби/наеми, град, тип, площ, цена, код на обява, сортиране, страници |
| `/property?id=…` | Детайл: галерия, характеристики, описание, запитване, любими, подобни имоти |
| `/new-construction` | Ново строителство: проекти с диапазон на цените и брой свободни жилища + всички жилища ново строителство |
| `/project?id=…` | Страница на проект: описание, свободни жилища, запитване |
| `/blog`, `/post?slug=…` | Блог със статии, управляван от админ панела |
| `/members` | Екип по градове с филтър |
| `/stipendii` | Стипендийна програма с форма за кандидатстване |
| `/dvustayni-apartamenti-sofia` и още 39 | SEO страници „тип + град“ (10 типа × 4 града) със сами филтрирани оферти |
| `/sitemap.xml`, `/robots.txt` | За търсачки |
| `/mortgage` | Ипотечен калкулатор + заявка за консултация |
| `/advert` | Подробна форма „Обяви имот“ |
| `/about`, `/careers`, `/privacy` | За нас и екип, кариери с кандидатстване, лични данни |
| `/account` | Профил: любими имоти и известия за промяна на цената |
| `/admin` | Админ панел: имоти, запитвания, потребители |

## Всичко се променя от админа (`/admin`)
- **Съдържание и дизайн:** цветове на сайта (основен, акцентен, тъмен), контакти и социални мрежи, горна лента, футър, всички текстове и секции на началната страница (оферти, стъпки, числа, отзиви, въпроси – с добавяне, изтриване и подреждане), заглавия на всяка страница, „За нас“, екип със снимки, позиции в „Кариери“. Секциите на началната страница могат да се скриват.
- **Снимки:** бутон „Качи“ при имоти, проекти, статии, екип и фонова снимка на началната страница. Снимките се оразмеряват в браузъра (до 1600 px) и се пазят в Neon (`/api/image?id=…`).
- **Имоти:** допълнителен етикет върху снимката (напр. „Топ оферта“), отметка „Покажи първа на началната страница“ и бутон „Дублирай“.
- **Контакти:** всички хора, оставили запитване, с профил или без; „Виж профила“ показва данните, любимите имоти, всички запитвания и бележки за контакта. CSV експорт на контактите и запитванията.

## Профили и любими
Регистрация и вход с имейл и парола (поне 8 символа и цифра). Паролите се пазят като `scrypt` хеш, а сесията е в `HttpOnly`/`Secure`/`SameSite=Strict` бисквитка. Сърцето на всяка обява я запазва в любими и записва текущата цена – ако цената се промени, в профила се показва известие. *Изпращане на имейли, вход с Google, „забравена парола“ и превод на сайта (EN/RU) не са включени – изискват външни услуги или отделен превод.*

## Админ панел (`/admin`)
- **Имоти:** таблица с колони и редове, добавяне/редакция (сделка, тип, град, квартал, цена, площ, етаж, спални, строителство, обзаведен, ново строителство, описание, снимки), скриване, изтриване, търсене. Бутон „Примерни данни“ добавя 16 демо имота.
- **Запитвания:** всички заявки от формите (оферти, обяви, имоти, ипотека, кандидатури) със статус „ново/обработено“.
- **Проекти:** комплекси за „Ново строителство“; имотите се свързват с проект от формата на имота.
- **Блог:** добавяне/редакция на статии (адресът се генерира автоматично от заглавието).
- **Потребители:** регистрирани профили и брой любими.

На всяка страница има бутон „Запитване / Обади се / Вайбър“ (бързо запитване, което се записва в раздел „Запитвания“).

## Инсталиране във Vercel + Neon
1. Качи проекта в GitHub и го импортирай във Vercel (Framework Preset: **Other**).
2. **Storage / Integrations → Neon** → свържи към проекта (добавя `DATABASE_URL`).
3. В **Settings → Environment Variables** добави `ADMIN_PASSWORD` (по желание и `SESSION_SECRET`). Виж `.env.example`.
4. Redeploy. Таблиците (`properties`, `projects`, `posts`, `settings`, `images`, `users`, `favorites`, `leads`) се създават автоматично при първата заявка. Ако вече имаш таблица `properties` от предишната версия, тя се надгражда сама (добавят се новите колони) и данните ти се запазват.

## Локално стартиране
```bash
npm i -g vercel
npm install
vercel link && vercel env pull .env.local   # изтегля DATABASE_URL; добави и ADMIN_PASSWORD
vercel dev
```

**Ако променяш стойностите по подразбиране в `lib/site.js`,** пусни `npm run gen:defaults`.

## Бележки
- Всички имена, цени, адреси, телефони и отзиви са измислени. Формите записват запитвания в базата (няма реални сделки и изпращане на имейли).
- Формите имат скрито поле-капан за ботове и ограничение по телефон (до 3 запитвания в минута).
- GitHub Pages не изпълнява `api/` функции – ползвай Vercel.
