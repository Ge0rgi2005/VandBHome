# VandBHome

Демонстрационен сайт на **измислената** брокерска фирма VandBHome. Вдъхновен от структурата на сайтове за директен откуп и продажба на имоти, с собствен дизайн (петролено синьо и шафранено жълто, шрифт Onest).

## Съдържание на страницата
Hero с двустъпкова форма · оферти от купувачи · цифри · филтрируеми обяви · отзиви · ново строителство · въпроси · контакт.

## Стартиране
Чист HTML/CSS/JS, без инсталация. Отвори `index.html` или стартирай `python3 -m http.server`.

## GitHub Pages
1. Качи папката в ново хранилище.
2. Settings → Pages → Source: **GitHub Actions**. Работният процес в `.github/workflows/pages.yml` публикува сайта при всеки push в `main`.

## Бележки
Всички имена, цени, телефони и отзиви са измислени. Формата не изпраща данни (няма бекенд).
